# 黄金分割 + 抛物线插值 算法详解

## 核心思想

单峰函数上每次只需评 2 个点就能淘汰 38% 的搜索空间。反复执行直到区间足够小，最后用抛物线插值精确定峰。

---

## 阶段一：黄金分割

### 一步的原理

```
搜索区间 [a, b]

    a ──────── c ──────── d ──────── b
              ↑           ↑
           38% 处      62% 处

    c = b - 0.618 × (b-a)
    d = a + 0.618 × (b-a)

评 f(c) 和 f(d):

  情况1: f(c) > f(d)          情况2: f(d) > f(c)
    a ── c ── d ── b            a ── c ── d ── b
         ↑    ↑                      ↑    ↑
       高    低                     低    高
         ↓                              ↓
    峰值在左侧                     峰值在右侧
    淘汰 [d, b]                   淘汰 [a, c]
    新区间: [a, d]                新区间: [c, b]

区间缩小 38%
```

### N=31 完整模拟

```
第1步: 区间 [0, 30]
  c=11, d=19  →  f(11)=191, f(19)=200  →  f(d)大, 淘汰[0,11]
  新区间: [11, 30]  (剩19个点)

第2步: 区间 [11, 30]
  复用 d=19 作为新区间的 c
  只需评 1 个新点: d=23  →  f(23)=180  →  f(19)=200 > f(23)
  淘汰[23,30]
  新区间: [11, 23]  (剩12个点)

第3步: 区间 [11, 23]
  复用 c=19 作为新区间的 d
  评 1 个新点: c=15  →  f(15)=2321(!!)  →  f(15) > f(19)
  淘汰[19,23]
  新区间: [11, 19]  (剩8个点)

第4步: 区间 [11, 19]
  复用 c=15 作为新区间的 d
  评 1 个新点: c=14  →  f(14)=1500  →  f(15)=2321 > f(14)
  淘汰[11,14]
  新区间: [14, 19]  (剩5个点)

第5步: 区间 [14, 19]
  复用 d=15 作为新区间的 c
  评 1 个新点: d=17  →  f(17)=260  →  f(15) > f(17)
  淘汰[17,19]
  新区间: [14, 17]  (剩3个点)  ← 够小了

共评估 7 个点: 11, 19, 23, 15, 14, 17
已知: f(14)=1500, f(15)=2321, f(17)=260
```

## 阶段二：抛物线插值

### 原理

三点确定一条抛物线：

```
f(x) = ax² + bx + c

已知: (x₁,f₁), (x₂,f₂), (x₃,f₃)

顶点: x* = -b / (2a)

如果 a < 0 (开口向下):
  x* 就是峰值位置
```

### 在最终区间 [14, 17] 上

```
取三个点: (14, 1500), (15, 2321), (17, 260)

a = (260 - 2×2321 + 1500) / (2) =  (260 - 4642 + 1500) / 2
  = -2882 / 2 = -1441        ← a < 0 ✓ 开口向下

b = (2321 - 1500) - (-1441)×(14+15)
  = 821 + 1441×29
  = 821 + 41789 = 42610

x* = -b/(2a) = -42610 / (-2882) = 14.78

取整: 15    ← 预测峰值

验证: 评第 15 张  分数=2321 ← 确认
```

## 总流程

```
1. 黄金分割
   输入: N=31, 评估函数 f(x)
   每步评 1-2 点, 淘汰 38% 区间
   当区间 ≤ 4 个点时停止

2. 抛物线插值
   取区间内分数最高的 3 个点
   拟合 y = ax² + bx + c
   pred = round(-b/(2a))

3. 验证
   评价 f(pred), f(pred-1), f(pred+1)
   三选一返回最高分

总评估: 黄金 7 点 + 验证 1-2 点 = 8-9 点
```

## 为什么不怕局部波动

```
Tenengrad 曲线:
  2000│         ●
      │        ╱ ╲
  1500│    ●  ╱   ╲
      │   ╱  ╱     ╲
  1000│  ╱  ╱       ╲
      │ ╱  ╱         ╲
   500│╱  ●           ╲
      │╱              ╲
    0└┼──┼──┼──┼──┼──┼──→ 序号
      11 13 15 17 19 21

黄金分割评的点: 11, 19, 23, 15, 14, 17
间距很大, 天然绕过了小波动 → 不会误判
最后抛物线插值又修正了采样间隔带来的偏差
```
