# 视觉软件 ↔ PLC 通信协议

**版本**: V1.0
**传输层**: TCP
**编码**: ASCII，每条指令以 `\r\n` 结尾

---

## 1. 协议概述

```
视觉软件 (TCP Client) ←→ PLC (TCP Server)

请求-响应模式：视觉发指令，PLC 回复确认后执行，执行完毕再回复结果。
所有指令大小写敏感。
```

---

## 2. 指令集

### 2.1 版本协商

```
视觉 → PLC:  HELLO,<协议版本>\r\n
PLC  → 视觉:  HELLO,<协议版本>,<轴行程最小值>,<轴行程最大值>,<最大速度>\r\n
```

| 字段 | 类型 | 说明 |
|---|---|---|
| 协议版本 | int | 当前为 1 |
| 轴行程最小值 | float | 物理下限 (mm) |
| 轴行程最大值 | float | 物理上限 (mm) |
| 最大速度 | float | 飞拍最高速度 (mm/s) |

---

### 2.2 等步长飞拍

```
视觉 → PLC:  CAPTURE,<起点>,<终点>,<步距>,<触发间隔>\r\n
PLC  → 视觉:  OK\r\n
PLC  → 视觉:  CAPTURE_DONE,<实际拍到的张数>\r\n
```

| 字段 | 类型 | 说明 |
|---|---|---|
| 起点 / 终点 | float | Z 轴位置 (mm)，起点可大于终点 |
| 步距 | float | 相邻触发点间距 (mm)，必须 > 0 |
| 触发间隔 | int | 相邻触发时间间隔 (ms) |
| 实际拍到的张数 | int | 含首尾 |

示例:
```
→ CAPTURE,0,100,3,10\r\n     // 0mm→100mm，每3mm触发一次，间隔10ms
← OK\r\n
← CAPTURE_DONE,34\r\n
```

---

### 2.3 指定点位飞拍

```
视觉 → PLC:  CAPTURE_LIST,<触发间隔>,<p1>,<p2>,<p3>...\r\n
PLC  → 视觉:  OK\r\n
PLC  → 视觉:  CAPTURE_DONE,<张数>\r\n
```

| 字段 | 类型 | 说明 |
|---|---|---|
| 触发间隔 | int | ms |
| p1,p2... | float | 点位列表，按运动顺序排列 |

示例:
```
→ CAPTURE_LIST,10,0,15,32,50,68,71,75\r\n
← OK\r\n
← CAPTURE_DONE,7\r\n
```

---

### 2.4 移动到指定位置

```
视觉 → PLC:  MOVE_TO,<目标位置>\r\n
PLC  → 视觉:  OK\r\n
PLC  → 视觉:  MOVE_DONE\r\n
```

| 字段 | 类型 | 说明 |
|---|---|---|
| 目标位置 | float | Z 轴位置 (mm) |

---

### 2.5 查询当前位置

```
视觉 → PLC:  GET_POS\r\n
PLC  → 视觉:  POS,<当前Z>\r\n
```

---

### 2.6 急停

```
视觉 → PLC:  STOP\r\n
PLC  → 视觉:  STOPPED\r\n
```

任何状态下收到 `STOP` 立即中止当前动作并回复。

---

### 2.7 异常上报

```
PLC  → 视觉:  ERROR,<错误码>,<描述>\r\n
```

---

## 3. 错误码

| 码 | 描述 |
|---|---|
| 1 | 指令格式错误（字段数不对/类型错误） |
| 2 | 点位超出轴行程范围 |
| 3 | 步距或触发间隔 ≤ 0 |
| 4 | 飞拍速度超过最大速度限制 |
| 5 | 运动中收到不可执行指令 |
| 6 | 轴驱动器报警 |
| 7 | 限位触发 |
| 8 | 触发信号异常（未收到相机完成信号） |
| 9 | 未知指令 |
| 99 | 内部异常 |

---

## 4. 超时与重试

| 场景 | 超时 | 重试次数 | 失败后动作 |
|---|---|---|---|
| 发指令后未收到 `OK` | 500 ms | 1 | 抛异常，流程终止 |
| `OK` 后未收到完成信号 | 30 s | 0 | 发 `STOP`，流程终止 |
| `GET_POS` 无响应 | 500 ms | 1 | 返回 None |
| `HELLO` 无响应 | 3 s | 2 | TCP 重连，3 次后报错 |

## 5. 完整时序示例

### 全扫模式

```
视觉                                  PLC
 │                                     │
 │── HELLO,1 ────────────────────────→│
 │←── HELLO,1,-10,120,50 ─────────────│  (行程 -10~120mm, 最高 50mm/s)
 │                                     │
 │── CAPTURE,0,100,1,10 ─────────────→│  等步长全扫
 │←── OK ─────────────────────────────│
 │                                     │  [飞拍中...]
 │←── CAPTURE_DONE,100 ───────────────│
 │                                     │
 │  [Tenengrad 评价 100 张, 最佳=68]    │
 │                                     │
 │── MOVE_TO,68 ──────────────────────→│
 │←── OK ─────────────────────────────│
 │                                     │  [移动中...]
 │←── MOVE_DONE ──────────────────────│
 │                                     │
 │  完成                                │
```

### 粗扫+精扫模式

```
视觉                                  PLC
 │                                     │
 │── HELLO,1 ────────────────────────→│
 │←── HELLO,1,-10,120,50 ─────────────│
 │                                     │
 │  阶段1: 粗扫                         │
 │── CAPTURE,0,100,3,10 ─────────────→│  步距=3, 等于粗扫步长
 │←── OK ─────────────────────────────│
 │←── CAPTURE_DONE,34 ────────────────│
 │                                     │
 │  [评价 34 张, 粗扫峰值=66]           │
 │  精扫范围 [63, 69]                   │
 │                                     │
 │  阶段2: 精扫                         │
 │── CAPTURE_LIST,10,63,64,65,67,68,69→│  跳过已评的66
 │←── OK ─────────────────────────────│
 │←── CAPTURE_DONE,6 ─────────────────│
 │                                     │
 │  [评价 6 张, 全局最佳=68]             │
 │                                     │
 │── MOVE_TO,68 ──────────────────────→│
 │←── OK ─────────────────────────────│
 │←── MOVE_DONE ──────────────────────│
```

## 6. 视觉软件端状态机

```
IDLE ──HELLO──→ CONNECTED
                  │
          ┌───────┼───────┐
          ↓       ↓       ↓
      CAPTURE  CAPTURE  MOVE_TO
       _LIST             
          │       │       │
        DONE    DONE    DONE
          │       │       │
          └───────┼───────┘
                  ↓
              IDLE (等待下次指令)
```
