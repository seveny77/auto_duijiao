# N=100 飞拍模式 CT 时序拆解

## 假设参数

| 参数 | 值 |
|---|---|
| 触发间隔 | 10 ms |
| 加/减速 | 各 50 ms |
| 评价计算 | 43 ms/次 (Tenengrad 2000x2000) |
| PLC 通讯 | 10 ms/次 |
| 回位移动 | 50 ms |

---

## 一、全扫

```
时间轴 (ms)
0    100   200   300   400   500   ...   1100  1200  1300  ...                    5400  5450  5500
|-----|-----|-----|-----|-----|       |------|-----|-----|                         |-----|-----|
| PLC | 加速 |············ 匀速飞拍 100 个触发点 ············| 减速 |                                                     |
|10ms |50ms |       100 × 10ms = 1000ms                     |50ms  |                                                     |
|     |     |  触发0  触发1  触发2  ...  触发99              |      |                                                     |
                                                                |········ 评价 100 张 ········| PLC | 回位 |
                                                                |     100 × 43ms = 4300ms     |10ms |50ms |
```

### 拆解

| 阶段 | 操作 | 耗时 | 占比 |
|---|---|---|---|
| ① PLC 发指令 | 上位机 → PLC：开始全扫 | 10 ms | 0.2% |
| ② 加速 | 电机从 0 加速到飞拍速度 | 50 ms | 0.9% |
| ③ 飞拍采图 | 匀速飞过 L，等间距触发 100 次 | 1000 ms | 18.3% |
| ④ 减速 | 电机减速到 0 | 50 ms | 0.9% |
| ⑤ 图像评价 | 逐张 Tenengrad × 100 | **4300 ms** | **78.8%** |
| ⑥ PLC 返回结果 | 上位机 → PLC：最佳序号 | 10 ms | 0.2% |
| ⑦ 回位 | 移动到最佳点 | 50 ms | 0.9% |
| **总计** | | **5470 ms (5.47s)** | |

                                                                          | 加速 |

### 拆解

| 阶段 | 操作 | 耗时 | 占比 |
|---|---|---|---|
| ① PLC 发粗扫指令 | 上位机 → PLC：粗扫点位列表 | 10 ms | 0.6% |
| ② 加速 | 电机加速 | 50 ms | 2.9% |
| ③ 粗扫飞拍 | 11 个触发点 | 110 ms | 6.4% |
| ④ 减速 | 电机减速 | 50 ms | 2.9% |
| ⑤ 粗扫评价 | 11 张 × 43ms | 473 ms | 27.7% |
| ⑥ PLC 发精扫指令 | 上位机 → PLC：精扫点位列表 | 10 ms | 0.6% |
| ⑦ 加速 | 电机加速 | 50 ms | 2.9% |
| ⑧ 精扫飞拍 | 20 个触发点 | 200 ms | 11.7% |
| ⑨ 减速 | 电机减速 | 50 ms | 2.9% |
| ⑩ 精扫评价 | 20 张 × 43ms | **860 ms** | **50.3%** |
| ⑪ PLC 返回结果 | 上位机 → PLC：最佳序号 | 10 ms | 0.6% |
| ⑫ 回位 | 移动到最佳点 | 50 ms | 2.9% |
| **总计** | | **1923 ms (1.92s)** | |
