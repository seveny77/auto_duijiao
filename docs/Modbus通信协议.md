# 视觉软件 ↔ PLC Modbus TCP 通信协议

**版本**: V1.0
**传输层**: Modbus TCP (端口 502)
**视觉软件**: Modbus Master (Client)
**PLC**: Modbus Slave (Server)

---

## 1. 寄存器映射

### 1.1 命令区 (视觉 → PLC, Holding Register, 功能码 06/16 写)

| 地址 | 名称 | 类型 | 说明 |
|---|---|---|---|
| 40001 | CMD_CODE | uint16 | 命令码 (写入触发执行) |
| 40002 | CMD_POS_START | float32 | 起点 (等步长飞拍用) |
| 40004 | CMD_POS_END | float32 | 终点 |
| 40006 | CMD_STEP | float32 | 步距 (mm) |
| 40008 | CMD_INTERVAL | uint16 | 触发间隔 (ms) |
| 40009 | CMD_TARGET_POS | float32 | 目标位置 (MOVE_TO 用) |
| 40011 | CMD_LIST_COUNT | uint16 | 点位数量 (CAPTURE_LIST 用) |
| 40012 | CMD_LIST_START | float32[] | 点位列表起始 (数量由 40011 指定) |

### 1.2 状态区 (PLC → 视觉, Holding Register, 功能码 03 读)

| 地址 | 名称 | 类型 | 说明 |
|---|---|---|---|
| 40101 | STA_STATUS | uint16 | PLC 状态码 |
| 40102 | STA_ERROR_CODE | uint16 | 错误码 (STA_STATUS=4 时有效) |
| 40103 | STA_CAPTURED_COUNT | uint16 | 实际拍到的张数 |
| 40104 | STA_CURRENT_POS | float32 | 当前 Z 轴位置 (mm) |

> float32 占 2 个寄存器 (大端序)，uint16 占 1 个。

---

## 2. 命令码

| 码 | 指令 | 需要填入的参数 |
|---|---|---|
| 1 | CAPTURE 等步长飞拍 | 40002~40008 |
| 2 | CAPTURE_LIST 指定点位 | 40008, 40011, 40012+ |
| 3 | MOVE_TO | 40009 |
| 4 | STOP | 无 |
| 5 | GET_POS | 无 |
| 0 | 保留/空闲 | - |

---

## 3. 状态码

| 码 | 状态 |
|---|---|
| 0 | IDLE (空闲，可接收新指令) |
| 1 | BUSY (正在执行) |
| 2 | DONE (执行完成) |
| 3 | STOPPED (已停止) |
| 4 | ERROR (异常，读 40102 获取错误码) |

---

## 4. 错误码

| 码 | 描述 |
|---|---|
| 1 | 点位超出轴行程 |
| 2 | 步距 / 间隔 ≤ 0 |
| 3 | 列表点位数量 = 0 或超限 |
| 4 | 运动中收到新指令 |
| 5 | 轴驱动器报警 |
| 6 | 限位触发 |
| 7 | 触发信号异常 |
| 8 | 未知命令 |
| 99 | 内部异常 |

---

## 5. 交互流程

### 通用模式

```
1. 视觉轮询读 40101 (STA_STATUS)，等待 IDLE (0)
2. 视觉写入参数到 40002~40012
3. 视觉写 40001 (CMD_CODE) 触发执行
4. PLC 将 40101 置为 BUSY (1)
5. 视觉轮询读 40101，等待 DONE (2)
6. 视觉读 40103 (CAPTURED_COUNT) 或其他结果
7. PLC 将 40101 置回 IDLE (0)
```

### 等步长飞拍

```
视觉                          PLC
 │                             │
 │ 读 40101 → IDLE              │
 │ 写 40002 = 0 (起点)          │
 │ 写 40004 = 100 (终点)        │
 │ 写 40006 = 3 (步距)          │
 │ 写 40008 = 10 (间隔ms)       │
 │ 写 40001 = 1 (CAPTURE) ────→│
 │                             │ 40101 → BUSY
 │                             │ [飞拍...]
 │ 轮询 40101...               │
 │ 40101 → DONE ←──────────────│
 │ 读 40103 = 34               │
 │                             │ 40101 → IDLE
```

### 指定点位飞拍

```
视觉                          PLC
 │                             │
 │ 写 40011 = 6 (6个点)         │
 │ 写 40012 = 63               │
 │ 写 40014 = 64               │
 │ ...                         │
 │ 写 40008 = 10               │
 │ 写 40001 = 2 (CAPTURE_LIST)→│
 │                             │ [飞拍...]
 │ 轮询 → DONE                 │
 │ 读 40103 = 6                │
```

### 移动

```
视觉                          PLC
 │                             │
 │ 写 40009 = 68               │
 │ 写 40001 = 3 (MOVE_TO) ────→│
 │                             │ [移动...]
 │ 轮询 → DONE                 │
```

### 查询位置 (无需等 IDLE)

```
视觉                          PLC
 │                             │
 │ 写 40001 = 5 (GET_POS) ────→│
 │ 轮询 → DONE                 │
 │ 读 40104 = 45.2 mm          │
```

---

## 6. 时序约束

| 规则 | 值 |
|---|---|
| 40101 轮询间隔 | 50 ms |
| 指令超时 | 30 s (超时后发 STOP) |
| CMD_CODE 写 0 清除 | 每次执行完成后 PLC 自动归 0 |
| float32 字节序 | 大端 (PLC 标准) |
