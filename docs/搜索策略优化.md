# 自动对焦（Auto Focus）快速寻优系统技术设计文档

**版本：V1.0**

------

# 1. 项目背景

## 1.1 应用场景

系统应用于工业视觉检测设备：

- 工业相机
- 远心镜头
- 精密运动平台（Z轴）
- 固定产品检测

通过调整相机与工件之间的工作距离，使采集图像达到最佳清晰度。

传统方案：

> 在整个Z轴范围内逐点采图 → 计算清晰度 → 找最大值

存在问题：

- 搜索点数量多
- CT（Cycle Time）高
- 峰值区域窄时需要高采样密度
- 每次重新扫描浪费历史信息

------

# 2. 问题定义

## 2.1 数学模型

定义：

[
S(z)
]

其中：

- z：Z轴位置
- S：清晰度评价值

目标：

寻找：

[
z^*=\arg\max S(z)
]

------

## 2.2 场景特点

本项目具有以下特点：

### 特点1：产品固定

同一产品：

清晰度响应曲线形状稳定。

即：

[
S(z)=F(z-\Delta z)
]

其中：

- F(z)：固定焦点响应曲线
- Δz：由于来料高度变化产生的位置偏移

------

### 特点2：峰值位置随机

实际情况：

模板：

```
index

0 ----------------100

          peak
           |
          50
```

下一次：

```
0 ----------------100

                    peak
                     |
                    85
```

因此：

峰可能：

[
z_{peak}\in[0,100]
]

------

### 特点3：曲线非严格单峰

存在：

- 局部极值
- 噪声波动
- 次峰

因此不采用：

- 黄金分割搜索
- 三分搜索
- 单纯爬山算法

------

# 3. 总体技术路线

## 3.1 核心思想

由：

> 搜索最大值

转变为：

> 利用历史曲线先验，快速定位峰值区域。

```
             首次标定

                 |

                 |

                 |
                 |
       自适应加密采样
                 |
                 |
       峰值拟合优化
                 |
                 |
          输出最佳Z
```

目的：

降低：

- 图像噪声
- 机械振动影响

- 峰形

[

# 6. 特征提取

## 6.1 峰位置 Peak Position

定义：

[
z_p=\arg\max S(z)
]

实际：

采用二次曲线拟合。

取峰附近：

```
z-1

z

z+1
```

拟合：

[
S(z)=az^2+bz+c
]

峰：

[
z_p=-\frac{b}{2a}
]

------

## 6.2 峰宽 Peak Width

采用：

FWHM

定义：

# [ S_{half}

\frac{S_{max}+S_{base}}2
]

寻找：

左右交点：

```
        peak

          *
        *****
------********-----
      |     |

      left right
```

峰宽：

[
W=z_r-z_l
]

用途：

判断：

- 景深
- 对焦可靠性

------

## 6.3 Shape Descriptor

用于描述：

> 曲线形态

计算：

以峰为中心：

[
x=z-z_p
]

归一化：

[
y=
\frac{S-S_{min}}
{S_{max}-S_{min}}
]

例如：

保存：

```
x:

-10
-9
...
0
...
10


y:

0.1
0.2
...
1
...
```

形成：

```
shape_descriptor:

[
0.05,
0.08,
0.15,
...
1,
...
]
```

# 8. 曲线模板匹配扩展方案

如果需要进一步减少采样：

采用：

## NCC模板匹配

模板：

[
T(x)
]

当前：

[
C(x)
]

寻找：

[
offset
]

使：

[
NCC(T(x-offset),C(x))
]

最大。

流程：

```
模板曲线

       ↓

不同offset滑动

       ↓

计算相关系数

       ↓

最大值位置

       ↓

预测峰位置
```

适合：

- 曲线完全稳定
- 高度变化大

# 9. 异常处理策略

## 9.1 模板失效判断

计算：

当前曲线与模板差异：

[
Loss=
||C-T||
]

如果：

```
Loss > threshold
```

认为：

- 产品变化
- 光学异常
- ROI异常

重新完整扫描。

------

## 9.2 多峰处理

如果：

发现：

多个峰：

```
峰1

峰2

峰3
```

策略：

选择：

- 模板相似度最高峰
- 峰值最高峰
