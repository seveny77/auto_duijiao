# 相机适配器 v1 开发计划

## 摘要

新增 `camera_adapter.py`，封装海康 MvCameraControl SDK，提供单帧采图、回调取流、硬件降采样、ROI 开窗、软触发模拟等功能。与 `evaluator_opencv.py` 模式一致——一个类、统一接口。

## 开发步骤（4 步）

### Step 1: SDK 联通测试

验证 Python 能正确加载 SDK 并枚举设备。

- 用 `sys.path.append` 引用 `F:/Program Files/MVS/Development/Samples/Python/MvImport/`
- `MV_CC_Initialize()` → `MV_CC_EnumDevices()` → 打印设备名、序列号
- 测试连接 → 打开 → 关闭 → 销毁句柄 → `MV_CC_Finalize()`

**验收**：打印出相机型号 `MV-CH120-60UM` 和序列号。

### Step 2: 单帧采图 + 参数设置

封装为 `HikCamera` 类。

- `open()` / `close()`
- `capture(timeout_ms)` → 返回 BGR numpy 数组，保存为图片验证
- `set_roi(x, y, w, h)` → 硬件开窗
- `set_binning(h, v)` → 硬件 Binning 降采样（1×1 / 2×2 / 4×4）
- `set_decimation(h, v)` → 硬件 Decimation 降采样
- `set_exposure(value_us)` / `set_gain(value)`
- `set_trigger_mode(mode)` → `"off"` / `"software"` / `"hardware"`
- `trigger_software()` → 软触发一次（模拟硬触发）

**验收**：
1. `capture()` 返回的 numpy 数组能正常显示/保存
2. `set_roi(0,0,512,512)` 后 `capture()` 返回 512×512 图像
3. `set_binning(2,2)` 后图像尺寸减半

### Step 3: 回调取流

增加飞拍所需的连续采图+回调模式。

- `start_stream(callback)` → 注册回调，启动取流
  - 回调函数签名：`callback(np_array)`，np_array 为 BGR 格式
  - 回调内部：SDK 帧 → ctypes 转换 → numpy → 调用户 callback → 释放帧缓冲
- `stop_stream()` → 停止取流

**软触发模拟硬触发的测试流程：**
```python
cam.set_trigger_mode("software")
frame_count = [0]
def on_frame(img):
    frame_count[0] += 1
    print(f"收到第 {frame_count[0]} 帧, shape={img.shape}")

cam.start_stream(on_frame)
for i in range(100):
    cam.trigger_software()
    time.sleep(0.010)  # 模拟 10ms 触发间隔
cam.stop_stream()
# 预期：收到 100 帧
```

**验收**：软触发 100 次，回调收到 100 帧，无丢帧。

## 完整类接口

```python
class HikCamera:
    def __init__(self, camera_index=0)
    def open(self)
    def close(self)
    def capture(self, timeout_ms=1000) -> np.ndarray | None
    def start_stream(self, callback)
    def stop_stream(self)
    def set_roi(self, x, y, w, h)
    def set_binning(self, h, v)
    def set_decimation(self, h, v)
    def set_exposure(self, value_us)
    def set_gain(self, value)
    def set_trigger_mode(self, mode)  # "off" / "software" / "hardware"
    def trigger_software(self)
    @property width -> int
    @property height -> int
```
