# 基于深度学习的单帧对焦验证计划

**版本：V1.0（2026-08-12）**

## 1. 背景与目标

当前固定场景对焦采用 **T 方法（Tenengrad 清晰度评价）+ 粗扫+精扫**，步距 5 μm，需要多次采图与运动。

目标：训练一个深度学习回归模型，**输入当前工作距离处的一帧图，直接输出离最佳焦点的偏移 Δz（μm）**，机构只做一次位移即可对焦到位，替代粗扫+精扫。

约束与当前边界：

| 项 | 当前确认结论 |
|---|---|
| 部署环境 | GPU 推理；单帧推理 < 20 ms（降采样下） |
| 当前阶段 | 只验证模型精度，模型只输出预测结果 |
| 精度基准 | 5 μm 步距（标签按 5 μm 量化） |
| 数据规模 | 先验证 **1 个物料** 的可行性；后续再用 T 方法全扫批量采集 |
| 标签定义 | 每个工件单独全扫出 best，标签为相对偏移 Δz = (best_idx − idx) × 5 μm；实际理想焦面会漂移，不做全局绝对位置 |

## 2. 数据现状盘点（2026-08-12）

## 3. 验证阶段

### Phase 0 · 方向可分性验证（AI 模型验证）

**目的**：单帧回归成立的前提是"距焦点 ±d 的图像存在可被模型学习的差异（方向可分）"。用户已观察到两侧图像有差异，需用 AI 模型定量验证。

**内容**（脚本：`verify_dl_direction.py`）：

1. 图像层统计：对每个 |d| 比较 best+d 与 best−d 两图的 MAE / NCC / 均值差，并与随机图对基线对比；
2. AI 方向二分类：小型 CNN 输入单帧 ROI patch，预测方向（+/−），按 d 分组划分训练/测试（训练偶数 d、测试奇数 d，验证跨偏移量的泛化），报告整体与逐 d 准确率（基线 50%）；
3. （可选）有符号偏移回归：同一骨干回归 Δz（index），报告 MAE（index/μm）与方向错误率。

**验收标准**：

| 结果 | 结论 |
|---|---|
| 方向准确率 ≥ 80%（且显著高于 50%） | 单帧方向可分，进入 Phase 1 |
| 方向准确率 ≈ 50% | 单帧方向不可学；改"两帧差分"或"清晰度给幅度 + 其他先验给方向" |

**产出**：方向准确率 vs d 曲线、对称性统计表、文本报告。

### Phase 1 · 数据采集与标注

- 采集工具：复用 `capture_scan.py` / T 方法全扫，每个样本在行程内按 5 μm 步距全扫 N 帧。
- 标注流程（每样本独立）：
  1. 全扫采图（index = Z 顺序）；
  2. 中心 ROI（或 YOLO ROI）+ Tenengrad 全扫找 best_idx；
  3. 标签 Δz_um = (best_idx − idx) × 5；
  4. 记录每样本 best 绝对位置 → 统计漂移量。
- 输入约定：ROI 裁剪 → 灰度 → resize（如 224×224），与推理端预处理完全一致。
- 存储建议：
  ```
  data/dlfocus/
  ├── sample_001/img_0000.jpg ... img_0399.jpg
  ├── sample_002/...
  └── dataset.csv   # sample_id, img_path, idx, z_um, delta_um, best_z
  ```
- 当前 1 个物料即可启动；多物料阶段按 sample 分组划分 train/val/test。

### Phase 2 · 模型

- 网络：小型 CNN 回归（3~4 层卷积，参数量 ~1-5M，保证 GPU 推理 < 20 ms）或 ResNet18 微调后蒸馏；输出 Δz（μm），损失 Smooth L1。
- 输入：224×224 灰度 ROI patch（训练与推理统一）。
- 数据划分：
  - 单物料可行性阶段：按 Z 位置随机划分（train/val/test）；
  - 多物料阶段：**按样本分组**，杜绝同一样本泄漏。
- 基线对照：Tenengrad/Laplacian 特征回归 |Δz|、粗精扫结果，量化深度学习增量。
- 训练环境：conda base（torch 2.7.1 + CUDA）。
- 数据增强：随机裁剪/平移、亮度抖动、轻微高斯噪声；**方向任务不翻转为宜**（防止翻转改变方向语义）。

### Phase 3 · 离线评估

| 指标 | 说明 |
|---|---|
| MAE（μm） | 预测 Δz 与标签平均绝对误差 |
| ±1 index / ±2 index 命中率 | 5 μm / 10 μm 容差内命中比例 |
| 方向错误率 | 预测符号错误比例（最关键） |
| 分段表现 | 按 |Δz| 分档（小偏移/中偏移/大偏移）分别统计 |
| 边界与低对比度 | 峰值贴边、信号弱样本的表现 |

**验收候选标准**（待真机数据确认）：MAE ≤ 5 μm，±2 index 命中率 ≥ 90%，方向错误率 ≤ 2%。

### Phase 4 · 真机验证

- 随机 Z 位置拍一帧 → 模型预测 Δz → 一次位移 → 拍确认帧，与全扫最优对比。
- CT 对比：单帧方案（采图 + 推理 + 单次移动）vs 当前粗精 ~1.9 s。
- 鲁棒性：曝光/增益/光照变化、温度漂移、不同工件。

### Phase 5 · 部署与后续优化

- GPU 推理集成，目标 < 20 ms；现阶段模型只输出预测结果。
- 依据验证结果决定：置信度/回退策略（低置信度或预测贴近行程边界时回退粗精扫）。
- 后续方向：多物料泛化、模型蒸馏/量化、T 方法自动采集流水线。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| 单帧方向不可学（±d 图像过于对称） | Phase 0 先验证；备选方案：两帧差分、清晰度幅度 + 方向先验 |
| 单物料过拟合，多物料不泛化 | 多物料采集 + 按样本分组划分 |
| 标签噪声（5 μm 量化、T 曲线局部抖动） | 曲线平滑、置信度加权、人工抽检 |
| 训练与推理预处理不一致 | 统一 ROI/灰度/resize/归一化管线 |
| 光照与曝光漂移 | 数据增强 + 归一化；真机鲁棒性测试 |
| 大偏移段方向学习困难 | 分段统计；必要时训练集中加大偏移样本权重 |
