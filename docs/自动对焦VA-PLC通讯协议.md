## 握手（初始化）

| 工位 | 信号名 | PLC→VA 地址 | VA→PLC 地址 | 说明 |
|---|---|---|---|---|
| 自动对焦 | 握手 |  | D3201 | VA 写入非零即发起，值=协议版本号 |
|  | 握手_完成 | D3301 |  | PLC 置 1，数据已就绪 |
|  | 握手_版本 | D3302 |  | PLC 确认的版本号 |
|  | 行程最小值 | D3303-D3304 |  | 丝杆物理最小位置 (μm)，32 位 |
|  | 行程最大值 | D3305-D3306 |  | 丝杆物理最大位置 (μm)，32 位 |
|  | 电机速度 | D3307-D3308 |  | 飞拍时电机速度 (μm/s)，32 位 |

## 等步长飞拍

> PLC 从丝杆原点拍到终点，全行程覆盖。VA 只指定步距和触发间隔。

| 工位 | 信号名 | PLC→VA 地址 | VA→PLC 地址 | 说明 |
|---|---|---|---|---|
| 自动对焦 | 飞拍_步距 |  | D3202-D3203 | 物理步距 (μm)，32 位 |
|  | 飞拍_触发间隔 |  | D3204 | 触发间隔 (ms)，写 0 则由 PLC 按步距/速度自动计算 |
|  | 飞拍_触发 |  | D3205 | VA 置 1，开始飞拍 |
|  | 飞拍_确认 | D3309 |  | PLC 置 1，已收到指令并开始 |
|  | 飞拍_完成 | D3310 |  | PLC 置 1，全部拍照完成 |
|  | 飞拍_张数 | D3311 |  | PLC 写入，实际拍到的张数 |

## 移动到指定位置

| 工位 | 信号名 | PLC→VA 地址 | VA→PLC 地址 | 说明 |
|---|---|---|---|---|
| 自动对焦 | 定点_目标序号 |  | D3206 | VA 写入，目标 index |
|  | 定点_触发 |  | D3207 | VA 置 1，开始移动 |
|  | 定点_确认 | D3312 |  | PLC 置 1，已收到指令 |
|  | 定点_完成 | D3313 |  | PLC 置 1，移动+拍照完成 |

## 流程结束

| 工位 | 信号名 | PLC→VA 地址 | VA→PLC 地址 | 说明 |
|---|---|---|---|---|
| 自动对焦 | 流程_完成 |  | D3208 | VA 置 1，本轮自动对焦全部结束 |

## 错误

| 工位 | 信号名 | PLC→VA 地址 | VA→PLC 地址 | 说明 |
|---|---|---|---|---|
| 自动对焦 | 错误码 | D3314 |  | 0=正常，1=参数无效，2=超时，3=电机故障，4=相机故障 |

## 交互时序

### 1. 握手

```
VA                                    PLC
 |                                     |
 |-- D3201=1 (握手，版本=1)             |
 |                                     |-- 读取 D3201=1
 |                                     |-- 写入 D3302=1 (握手_版本)
 |                                     |-- 写入 D3303~D3308 (行程+速度)
 |                                     |-- 写入 D3301=1 (握手_完成)
 |   <------------------------------   |
 |-- 读取 D3301, D3302                 |
 |-- 读取行程范围                       |
 |-- 写入 D3201=0 (清除)               |
 |                                     |-- 写入 D3301=0 (清除完成)
```

### 2. 等步长飞拍

```
VA                                    PLC
 |                                     |
 |-- D3202~3203=50 (步距 0.05mm)       |
 |   D3204=0 (触发间隔=自动)           |
 |   D3205=1 (飞拍_触发)               |
 |                                     |-- 批量读取 D3202~D3205
 |                                     |-- 触发间隔 = D3204>0 ? D3204 : 步距/速度
 |                                     |-- 写入 D3309=1 (飞拍_确认)
 |   <------------------------------   |
 |                                     |
 |   无交互！PLC 内部执行：             |
 |   从丝杆原点到终点，按步距等间隔     |
 |   逐点触发相机采图                   |
 |                                     |
 |                                     |-- 写入 D3311=N (拍到的张数)
 |                                     |-- 写入 D3310=1 (飞拍_完成)
 |   <------------------------------   |
 |-- 读取 D3310, D3311                 |
 |-- 写入 D3205=0 (清除触发)           |
 |                                     |-- 写入 D3310=0 (清除完成)
```

### 3. 移动到指定位置

```
VA                                    PLC
 |                                     |
 |-- D3206=68 (目标 index)             |
 |   D3207=1 (定点_触发)               |
 |                                     |-- 读取 D3206~D3207
 |                                     |-- 写入 D3312=1 (定点_确认)
 |   <------------------------------   |
 |                                     |-- 查表: index 68 → 物理位置
 |                                     |-- 电机移动到该位置
 |                                     |-- 触发一次拍照
 |                                     |-- 写入 D3313=1 (定点_完成)
 |   <------------------------------   |
 |-- 读取 D3313                        |
 |-- 写入 D3207=0 (清除触发)           |
 |                                     |-- 写入 D3313=0 (清除完成)
```

### 4. 流程结束

```
VA                                    PLC
 |                                     |
 |-- D3208=1 (流程_完成)               |
 |                                     |-- PLC 收到后进入下料/下一件
```

## 寄存器总览

### VA → PLC (D3200~D3208)

| 地址 | 信号名 | 类型 | 说明 |
|---|---|---|---|
| D3200 | VA心跳 | uint16 | 1s 自增 0~65535 |
| D3201 | 握手 | uint16 | 非零=触发，值=协议版本 |
| D3202-D3203 | 飞拍_步距 | uint32 | 物理步距 (μm) |
| D3204 | 飞拍_触发间隔 | uint16 | ms，0=PLC 自动计算 |
| D3205 | 飞拍_触发 | uint16 | 1=开始 |
| D3206 | 定点_目标序号 | uint16 | |
| D3207 | 定点_触发 | uint16 | 1=开始 |
| D3208 | 流程_完成 | uint16 | 1=本轮结束 |

### PLC → VA (D3300~D3314)

| 地址 | 信号名 | 类型 | 说明 |
|---|---|---|---|
| D3300 | PLC心跳 | uint16 | 1s 自增 0~65535 |
| D3301 | 握手_完成 | uint16 | 1=数据就绪 |
| D3302 | 握手_版本 | uint16 | 确认的版本号 |
| D3303-D3304 | 行程最小值 | uint32 | μm |
| D3305-D3306 | 行程最大值 | uint32 | μm |
| D3307-D3308 | 电机速度 | uint32 | μm/s |
| D3309 | 飞拍_确认 | uint16 | 1=已收到 |
| D3310 | 飞拍_完成 | uint16 | 1=拍照完成 |
| D3311 | 飞拍_张数 | uint16 | 实际张数 |
| D3312 | 定点_确认 | uint16 | 1=已收到 |
| D3313 | 定点_完成 | uint16 | 1=移动+拍照完成 |
| D3314 | 错误码 | uint16 | 0=正常 |
