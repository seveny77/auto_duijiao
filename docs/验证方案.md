# 完整验证方案：离线 Python → 上线 SDK

## Summary

分两阶段：① 离线用 Python + 真实图片验证搜索算法正确性，产出清晰度曲线和对比报告；② 上线时将评价模块替换为 SDK 的 `scImageSharpness`，搜索状态机不变。

## verify_offline.py — 验证主流程

```
输入: 图片文件夹路径, ROI (x,y,w,h), coarse_step (0=自动)

执行:
  1. 按文件名排序加载所有图片 → images[]

  2. 全扫（ground truth）
     FOR i in 0..N-1:
         score = evaluate(images[i], roi)
     记录: best_index_full, best_score_full, time_full

  3. 粗扫+精扫（使用 platform_search.py 交互协议）
     模拟平台循环:
         platform_search_step()                → g_NextIndex, g_IsDone
         模拟评估: score = evaluate(images[g_NextIndex], roi)
         写回: g_Score = score
     直到 g_IsDone == 1
     记录: best_index_coarse, best_score_coarse, visited_indices, time_coarse

  4. 对比报告:
     - 找到的序号是否一致? (best_index_coarse == best_index_full?)
     - 如果不是，分数差距有多大?
     - 评估次数: 全扫 N vs 粗扫+精扫 M
     - 减少比例: (1 - M/N) × 100%
     - 耗时对比

  5. 输出:
     - 终端打印对比表
     - 清晰度曲线图 (清晰度 vs 序号，标注粗扫点/精扫点/峰值)
```

## adapters/evaluator_opencv.py — 离线评价适配器

```python
class OpenCVSharpnessEvaluator:
    """用 OpenCV Laplacian 模拟 SDK，接口和 SDK 对齐"""
    def __init__(self):
        self.last_score = 0.0

    def evaluate(self, image_path, roi):
        """读图 → 裁 ROI → Laplacian 方差 → 返回 float"""
        img = cv2.imread(image_path)
        patch = img[roi[1]:roi[1]+roi[3], roi[0]:roi[0]+roi[2]]
        gray = cv2.cvtColor(patch, cv2.COLOR_BGR2GRAY)
        lap = cv2.Laplacian(gray, cv2.CV_64F)
        self.last_score = lap.var()
        return self.last_score
```

## 验证通过标准

| 指标 | 标准 |
|---|---|
| 峰值序号匹配 | `abs(best_index_coarse - best_index_full) ≤ 2` |
| 评估次数 | `M < N`（必须比全扫少） |
| 单峰验证 | 清晰度曲线呈明显单峰（视觉检查） |
| 边界覆盖 | 峰值不在第一张或最后一张（在 WD 有效范围内） |

## Test Plan

| 测试场景 | 方法 | 预期 |
|---|---|---|
| 单峰干净曲线 | 离线跑 100 张真实图 | 峰值匹配，减少 >60% |
| 不同 coarse_step | 分别跑 step=5/10/20 | 步长越大评估越少，精度可能略降 |
| 不同 ROI 大小 | 全图 vs 500×500 vs 200×200 | ROI 越小越快，曲线形状基本一致 |
| 异常输入 | 空文件夹、单张图、两张图 | 不崩溃，输出合理 |
| 峰值在边界 | 模拟 peak=0 或 peak=N-1 | 精扫范围正确 clip |

## Assumptions

- 真实图片按 WD 从小到大命名排序（如 `001.png, 002.png, ...`）
- 离线验证用 OpenCV Laplacian 作为 SDK 的近似替代，两者排序一致性高（同一张图谁更清晰，两个指标的结论一致）
- ROI 在整组图中位置固定（WD 变化导致的部件位移可忽略，或已通过模板匹配修正）
- 清晰度越高 = 图片越清晰（SDK 和 OpenCV 都满足）
