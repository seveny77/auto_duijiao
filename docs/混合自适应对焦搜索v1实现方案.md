# 混合自适应对焦搜索 v1 实现方案

## 摘要

新增 `AdaptiveGradientSearch` 类实现"自适应粗扫 → 梯度零交叉检测 → 二分加密 → 二次拟合"搜索策略，新增 `FocusTemplate` 模板系统和 `calibrate.py` 标定脚本。与现有 `CoarseToFineSearch` **平级独立**，共享相同接口，调用方自行选择策略。自适应方法遇到弱信号/多峰/拟合差时**不自动退化**，而是通过 `stats["quality"]` 暴露信号质量，由上层决策。

## 新增文件

| 文件 | 职责 |
|---|---|
| `focus_template.py` | `FocusTemplate` 类：FWHM 计算、shape_descriptor 提取、JSON 序列化 |
| `calibrate.py` | 离线标定脚本：全扫 → 生成模板 JSON → 退出 |

## 修改文件

| 文件 | 改动 |
|---|---|
| `platform_search.py` | 新增 `AdaptiveGradientSearch` 类 |
| `verify_offline.py` | 增加自适应策略对比测试（可选加载已有模板模拟生产场景） |

## Workflow

```
离线标定（只跑一次）
  calibrate.py --images ./0729/ --roi 2066,2662,300,300 --out template.json
    → 全扫 100 点 → 计算 FWHM + shape_descriptor → 保存 JSON

在线生产（每个新工件，调用方自行选择策略）
  方案A（自适应）:
    search = AdaptiveGradientSearch(N=100, template=template)
    while not done: idx = search.next(score); ...
    检查 search.stats["quality"]:
      "ok" → 直接用结果
      其他  → 调用方决定：接受 / 换 CoarseToFineSearch 重跑 / 告警

  方案B（粗精）:
    search = CoarseToFineSearch(N=100)
    ...
```

## 实现要点

### 1. `FocusTemplate`（`focus_template.py`）

数据结构：
```python
{
    "peak_width": 5.3,           # FWHM
    "peak_position": 68,         # 全扫峰所在 index
    "shape_descriptor": [...],   # ±2×FWHM 范围归一化分数，x 轴以峰为中心
    "z_offset": [-10, -9, ..., 10],  # shape_descriptor 对应的 index 偏移
    "meta": {"total_images": 100, "roi": [2066,2662,300,300]}
}
```

静态方法：
- `from_fullscan(scores, roi_info) -> FocusTemplate`：全扫分数 → FWHM（线性插值半高交点）+ shape_descriptor（±2×FWHM，min-max 归一化）

实例方法：
- `save(path)` / `load(path)`：JSON 读写

### 2. `AdaptiveGradientSearch`（`platform_search.py`）

构造函数：
```
AdaptiveGradientSearch(total_images, coarse_step=0, template=None)
```
- `coarse_step=0` 时：有模板取 `max(2, int(template.peak_width))`，无模板取 `N // 10`
- 模板只读，不写回

状态机：

| 阶段 | 触发 | 行为 |
|---|---|---|
| `coarse` | 初始 | 遍历粗扫点列表，逐个输出待评价 index |
| `gradient_detect` | 粗扫结束 | 计算相邻梯度 G_i = S_{i+1} - S_i；检测正→负翻转定位区间 [L, R]；**不设梯度阈值**，总能找到一个零交叉或最大梯度区间 |
| `bisect` | 区间定位完成 | 轮数 = `max(3, ceil(log2((R-L)/estimated_fwhm)) + 1)`；每轮采中点，比较左右梯度缩半区间 |
| `quadratic_fit` | 二分完成 | 取已知点中分数最高的 3 点做二次拟合 y=ax²+bx+c，输出亚 index 精度峰值 |

关键常量（类属性）：
- `MIN_BISECT_ROUNDS = 3`

**与 `CoarseToFineSearch` 的关系：平级独立，不互调。**

### 3. 信号质量暴露（`stats["quality"]`）

搜索完成后，`stats` 字典增加 `quality` 字段，取值：

| quality 值 | 含义 | 调用方可选动作 |
|---|---|---|
| `"ok"` | 梯度信号强，拟合 R² ≥ 0.85，单峰 | 直接使用结果 |
| `"low_gradient"` | `max(|G|) < median(|G|) × 5`，峰谷区分度不足 | 换粗精重跑 / 接受结果但标记低置信度 |
| `"poor_fit"` | 二次拟合 R² < 0.85，曲线不是标准抛物线 | 换粗精重跑 / 在二分区间内补采后取 max |
| `"multi_peak"` | 检测到 ≥2 个零交叉区间（次峰明显） | 换粗精重跑 / 人工检查 |

注意：`AdaptiveGradientSearch` 内部**不做任何自动切换**。以上 quality 只是信息，由 `stats` 携带出去，调用方读取后自行决策。

### 4. `calibrate.py`

```
python calibrate.py --images <path> --roi x,y,w,h [--out template.json]
```

- 加载图片、全扫评价（复用 `OpenCVSharpnessEvaluator`）
- 调用 `FocusTemplate.from_fullscan()` 生成模板
- 保存 JSON，打印 FWHM / peak_position / 耗时

### 5. `verify_offline.py` 改动

- `--template template.json`：加载模板后跑 `AdaptiveGradientSearch`
- 报告新增自适应策略行（评价数、耗时、误差、**quality**），与粗精并排对比
- 新增 `--strategy adaptive|coarse|both` 控制跑哪些策略（默认 both）

## 测试方案

| 场景 | 预期 |
|---|---|
| 0729 正常数据 | quality="ok"，评价 ≤ 15，误差 < 1 idx |
| 0729 + 加载模板 | FWHM=5.3，coarse_step=5（而非 10），quality="ok" |
| 加噪压低 P/V 到 ~3x | quality="low_gradient"，但仍返回最佳估计 |
| 双高斯叠加曲线 | quality="multi_peak"，选主峰返回 |
| 无模板首次运行 | coarse_step=N/10=10，正常走完自适应流程 |

## 假设

- 两种策略平级独立，调用方负责选择和切换
- 模板仅离线全扫生成，在线只读不写
- NCC 模板匹配（文档第 8 节）不在 v1 范围
- 粗扫始终均匀分布
- 模板 JSON 路径由调用方指定
