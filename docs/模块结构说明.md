# 模块结构说明

## 分层总览
- gui/       界面层：控件 / 服务 / 线程
- backend/   后端层：算法 / 流程 / 硬件工具（与界面无关）
- camera/ plc/   硬件驱动

## 各模块职责（表格）
| 模块 | 职责 |
|---|---|
| gui/app/widgets/ | 可复用控件（图像/曲线/日志/参数面板） |
| gui/app/services/ | 配置持久化 / 状态机 / CT 统计 |
| gui/app/workers/ | 后台线程（搜索 / 实时预览 / PLC 连接） |
| backend/pipeline.py | 流程编排：run_search / run_calibrate / run_phase |
| backend/ncc.py | NCC 算法（未来新方法的扩展位） |
| backend/detection.py | YOLO 检测 |
| backend/collector.py | 帧采集器 |
| backend/cli.py | 命令行入口 |
| verify_ncc_full.py | 薄壳：向后兼容 |

## 数据流
GUI 参数 → FocusConfig → worker → pipeline → SearchResult/CalibrateResult → GUI 显示

## 运行方式
- GUI：python -m gui.main
- CLI：python verify_ncc_full.py --action search/calibrate --mode real/sim ...
