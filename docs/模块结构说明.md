# 自动对焦 GUI 模块结构说明

## 1. 文档目的

本文档描述当前自动对焦 GUI 的代码分层、模块职责、线程关系、数据流和安全关闭流程。

当前维护范围以 GUI 及其直接依赖为主：

- `gui/`
- `backend/`
- `camera/`
- `plc/`
- `focus_template.py`
- `logging_config.py`
- `verify_ncc_full.py`

以下旧程序暂不作为当前 GUI 重构范围：

- `autofocus_controller.py`
- `capture_scan.py`
- `verify_dl_hybrid.py`

---
